# Role Color Everywhere

A Valenced-only plugin for Discord Android that applies server role colors to names throughout the client.

## Features

- **Message mentions:** Shows a user's role color when they're mentioned in chat.
- **Typing indicator:** Colors the names in the "is typing..." line in the current server channel.
- **Voice channels:** Colors the names of people connected to a voice channel using their highest usable role color.
- **Skip neutral colors:** Optionally ignores white, black, and gray roles so a more noticeable role color can be used.

## Settings

Open the plugin's settings to enable or disable typing indicator names, message mentions, and voice channel names.

You can also toggle **Skip White, Black & Gray Roles**. Turn it off if you want neutral role colors to show too.
